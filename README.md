# Python Object-Oriented Programming (OOP) Practicals

# Repository Overview

This repository contains Python practical assignments demonstrating various Object-Oriented Programming concepts, decorators, special methods, and design patterns.

---

# Practical 1 – Library Management System

## Overview

A menu-driven Library Management System that allows users to manage books, articles, and patrons.

## Features

- Add Books & Articles
- Register Patrons
- Borrow & Return Books
- Borrow & Return Articles
- Display Library Records
- Display Patron Details

## Concepts Used

- Classes & Objects
- Constructors
- Encapsulation
- Dictionaries & Lists

# Practical 2 – Dynamic Library Report Generator

## Overview

A Python application demonstrating decorators, class methods, static methods, and magic methods.

## Features

- Report Generation
- Activity Tracking
- Library Name Update
- Automatic Activity Counting

## Concepts Used

- Decorators
- Class Methods
- Static Methods
- Magic Methods (`__str__()`, `__len__()`)

# Practical 3 – Payment System using Strategy Design Pattern

## Overview

A payment processing system that implements the Strategy Design Pattern, allowing payment methods to be changed dynamically.

## Features

- Credit Card Payment
- PayPal Payment
- UPI Payment
- Reward Points

## Concepts Used

- Inheritance
- Polymorphism
- Method Overriding
- Strategy Design Pattern
